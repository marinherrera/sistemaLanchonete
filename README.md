# 🛒 Gerenciador de Vendas de Lanchonete

### Funcionalidades:

### Painel do Administrador
- **Cadastro de Produtos:** Registro de itens informando código manual, nome e preço (com validação para evitar códigos duplicados).
- **Listagem Geral:** Visualização completa de todos os produtos cadastrados no sistema.
- **Edição de Cadastro:** Atualização parcial ou total do nome e preço de um produto a partir do seu código.
- **Exclusão de Produtos:** Remoção de itens cadastrados na base de dados.

### Painel do Operador (Atendimento)
- **Abertura de Atendimento:** Identificação do operador responsável pelo caixa.
- **Lançamento de Itens:** Adição de produtos ao pedido digitando o código e a quantidade (com acúmulo automático caso o item seja inserido mais de uma vez).
- **Fechamento de Conta:** Exibição do resumo dos itens, cálculo do valor total e seleção da forma de pagamento (Dinheiro, Cartão ou Pix).

Sistema em Python desenvolvido como projeto acadêmico do 1º semestre
